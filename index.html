The YGN Framework

A complete hardware ecosystem for building guitar effects pedals

PCB Framework

Modular board designs with standardized IO, power management, and mounting. All circuits fully documented.

  • Three board sizes (S/M/L)
  • Unified IO board system
  • SMT-optimized layouts

Enclosures

Precision-milled aluminum enclosures designed to fit the PCB framework. CNC files and 3D models included.

  • Hammond 1590-compatible
  • FreeCAD source files
  • CNC toolpath included

Firmware

Pre-compiled firmware for relay switching, LED control, and power-on state management.

  • ATTiny-based control
  • True bypass switching
  • Simple one-command flashing
